# Jardin-de-eden
Jardín de Edén: Dashboard profesional para cultivadores con estética Streetwear. Gestión total del ciclo de vida, bitácora con fotos y alertas inteligentes. Incluye archivo de cosechas, wiki técnica y funciona 100% offline para máxima privacidad. Es una PWA instalable: control experto de tu cultivo, con estilo, en la palma de tu mano.
